# Tech Chess

A small chess website I built for a Web Techniques course, as my first university project. It is a static website that uses HTML, CSS and JavaScript.

It includes a short history of chess, pages about players and tournaments, and illustrated guides to the rules and board coordinates. The chess diagrams are generated from FEN positions with JavaScript.

## Run locally

Open `index.html` in a browser. No installation or server is needed. JavaScript must be enabled to display the diagrams.
